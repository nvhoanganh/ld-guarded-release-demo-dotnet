How it talks to Beacon

● request delivered → Beacon (HTTP 200)

Sent to Beacon's /flag-releases webhook with the x-beacon-secret header. Browser → Beacon is cross-origin, so a real deploy uses one of: (A) Beacon CORS + secret held in the page, or (B) a tiny proxy that keeps the secret server-side.
